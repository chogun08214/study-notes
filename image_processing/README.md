# 지능형 영상처리 (C++ / OpenCV)

「지능형 영상처리」 수업에서 실습한 코드를 정리한 저장소입니다.  
OpenCV는 **영상 입출력(imread / imshow / imwrite)에만** 사용하고, 필터링·히스토그램·보간·기하 변환·템플릿 매칭 같은 처리 알고리즘은 `int**` 2차원 배열 위에서 **직접 구현**했습니다.

- 코드: [`image_processing.cpp`](image_processing.cpp) (한 파일에 수업별 실습 함수 `exMMDD_n()` 누적)
- 실행: `main()`에서 원하는 실습 함수를 호출

## 공통 유틸리티

| 함수 | 역할 |
|---|---|
| `IntAlloc2` / `IntFree2`, `FloatAlloc2` | 2차원 영상 배열 동적 할당·해제 |
| `ReadImage` / `WriteImage` / `ImageShow` | 흑백 영상 읽기·저장·출력 (컬러 버전 포함) |
| `DrawHistogram` | 히스토그램 시각화 |
| `BilinearInterpolation` | 양선형 보간 |
| `ConnectedComponentLabeling` | 연결 요소 레이블링 |
