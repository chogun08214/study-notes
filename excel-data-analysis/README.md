# Excel 데이터 분석 실습

'빅데이터 이해 및 활용' 과목(A+)에서 수행한 엑셀 실습을 **데이터 정제 → 집계 → 통계 분석 → 시각화 → BI 데이터 모델** 흐름으로 정리했습니다.
공공데이터(KOSIS 사망원인통계, 교통사고 통계, 표준지 공시지가)와 교재 예제 데이터를 사용했습니다.

| 분류 | 사용 기능 |
|---|---|
| 데이터 정제 | Power Query(열 피벗 해제, 아래로 채우기, 여러 시트 통합, 사용자 지정 열), 고급 필터, 파생 변수 계산 |
| 집계 | 피벗 테이블, 계산 필드, 값 표시 형식(총합계 비율), GETPIVOTDATA, SUMIFS, 정렬 후 부분 집계 |
| 통계 분석 | 데이터 분석 도구(기술통계, 히스토그램, z-검정, t-검정, 일원분산분석, 상관분석, 회귀분석), CORREL |
| 시각화 | 막대·꺾은선·영역·산점도·거품형·방사형 차트, 이중 축 콤보 차트, 날짜 축, 추세선, 스파크라인, 조건부 서식, REPT |
| BI | Power Pivot 데이터 모델(판매 테이블 + 기준 테이블 8개), 측정값 |

## 데이터 정제

### 사망원인 데이터 파생 변수 계산 — `01`
- **데이터**: KOSIS 「사망원인통계」 성별 사망자 수 (1983~2021년)
- 가로로 펼쳐진 연도별 데이터를 세로 형태로 바꾸고, 연도마다 **합계, 남녀 차이, 남녀 비율, 백분율, 성별 사망자 비중, 전체 대비 비중**을 수식으로 계산
- SUM, AVERAGE, ROUND, ROUNDUP, COUNT, MIN, MAX, SMALL, LARGE로 요약 통계 산출
- 상대참조와 절대참조(`$E2`, `$E$42`)를 활용해 한 번 작성한 수식을 전체 행에 적용

### 교통사고 데이터 고급 필터 — `02`
- 시군구별·월별 교통사고 데이터 **5,489행**에서 조건 영역(2015년, 용산구)을 만들어 **고급 필터**로 해당 12개월 데이터만 추출

### 비구조화 데이터 정리 — `03`
- 거래처가 병합 셀로 묶이고 월이 열로 펼쳐진 표를 **Power Query**로 분석 가능한 형태로 변환
- 처리 단계: 데이터 형식 변경 → **열 피벗 해제(Unpivot)** 로 1~3월 열을 행으로 전환 → **아래로 채우기(Fill Down)** 로 빈 거래처 채우기
- `Sheet2`가 원본 표, `표1`이 변환 결과(`거래처 | 제품 | 월 | 금액`)입니다.

### 열 구성이 다른 지역별 데이터 통합 — `04`
- 서울·부산·대구·대전·전주 5개 시트의 판매 데이터가 **열 구성이 서로 달라** 단순 복사로 합칠 수 없는 상황
- Power Query에서 통합 문서의 시트 목록을 불러와 시트마다 헤더를 승격한 뒤 **하나의 표로 확장·통합**
- null 값 정리, **사용자 지정 열(원매출액 = 판매량 × 단가)** 추가
- 통합 결과를 SUMIFS로 **지역 × 결제방법별 판매량** 교차 집계

> 쿼리의 원본 경로가 작성한 PC의 로컬 경로로 되어 있어, 다른 환경에서 새로 고침하려면 Power Query 편집기에서 원본 경로를 바꿔야 합니다.

## 집계와 피벗 테이블

### 교통사고 피벗 테이블 분석 — `05`
- 원본에 **파생 열 `평균부상자수 = 부상자수 / 발생건수`** 를 추가해 사고 1건당 부상자 수를 계산
- 피벗 테이블 4개로 **시도 × 월** 기준 집계
  - 부상자수 합계, 부상자수 평균, 발생건수 합계, 사고 1건당 평균 부상자수
  - 보고서 필터로 연도(2015/2016)를 바꿔 가며 비교
- GETPIVOTDATA로 피벗 결과를 다른 셀에서 참조

### 피벗 테이블 계산 필드 — `06`
- 원본 데이터에 열을 추가하지 않고, 피벗 테이블 안에 **계산 필드 `발생건수당 부상자수 = 부상자수 / 발생건수`** 를 만들어 시도 × 월 기준으로 집계
- `05`의 파생 열 방식과 비교: 파생 열은 행마다 비율을 구한 뒤 평균을 내고, 계산 필드는 부상자수 합계를 발생건수 합계로 나누기 때문에 결과가 조금 다름

### 지점별 판매 데이터 집계 방법 비교 — `07`
같은 데이터를 세 가지 방법으로 집계해 결과를 비교
1. 정렬 후 SUM으로 집계
2. **SUMIFS** 함수로 지점 × 제품 교차 집계
3. **피벗 테이블**과 피벗 차트로 집계 (판매수량 합계·평균)

### 표준지 공시지가 피벗 분석 — `08`
- **데이터**: 2016년 표준지 공시지가 약 65,000건 (시도, 지목, 면적, 공시지가 등 23개 열)
- 피벗 테이블 3개로 분석
  - **시도별 공시지가 합계와 총합계 대비 비율**(값 표시 형식), 지목 보고서 필터
  - **시도 × 지목** 교차 집계
  - **계산 필드 `면적당 공시지가 = 공시지가 / 면적`** 로 시도 × 지목별 단위 면적당 가격 비교

## 통계 분석

데이터: 학생 60명의 설문 응답(Q1~Q16, 성별, 전공, 졸업연도)과 점수 데이터

### 기술통계 — `09`
- 데이터 분석 도구로 문항별 평균, 표준오차, 중앙값, 최빈값, 표준편차, 분산, 첨도, 왜도, 범위 산출
- 점수(Score) 분포를 히스토그램으로 확인

### 가설 검정 — `10`
| 검정 | 비교 대상 | 결과 |
|---|---|---|
| z-검정 (두 집단 평균) | 남녀 점수 | 평균 77.8 vs 79.7, 양측 p = 0.427 → 유의한 차이 없음 |
| t-검정 (등분산 가정) | 전공 2 vs 전공 4 점수 | 평균 84.2 vs 75.0, 양측 p = 0.004 → 유의한 차이 있음 |
| t-검정 (대응 표본) | 같은 학생의 Q1 vs Q2 응답 | 양측 p = 0.598 → 유의한 차이 없음 |
| 일원분산분석 | 전공 4개 집단(M1~M4) 점수 | F = 1.18, p = 0.339 → 집단 간 차이 없음 |

### 상관·회귀 분석 — `11`
- CORREL과 상관분석 도구로 점수(Score)와 MS·FS·PS 변수 간 **상관행렬** 작성 → Score와 가장 상관이 높은 변수는 FS (r = 0.79)
- 산점도에 선형·지수 추세선을 추가해 선형과 비선형 관계 비교
- 변수를 하나씩 추가하며 **회귀분석** 결과 비교

| 모형 | 독립변수 | 결정계수(R²) |
|---|---|---|
| 단순 회귀 | MS | 0.168 |
| 다중 회귀 | MS, FS | 0.629 |
| 다중 회귀 | MS, FS, PS | 0.732 |

→ 변수를 추가할수록 설명력이 높아지며, FS를 추가했을 때 가장 크게 증가
