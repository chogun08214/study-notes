# C++ 객체지향 프로그래밍

C++ 교재의 챕터별 실습(`chN.cpp`)과 예제 정리(`chN_final.cpp`), 시험 대비 연습 코드입니다. 한 파일에 여러 문제가 `/* ... */` 주석 블록으로 나뉘어 있어, 실행할 부분의 주석만 풀어서 컴파일합니다.

| 파일 | 주제 |
|---|---|
| `ch0.cpp`, `ch1.cpp` | C++ 시작 — `iostream`, `cin` / `cout`, `namespace`, `string`, `getline` |
| `ch2.cpp` | 포인터와 참조 복습 |
| `ch3.cpp` | 디폴트 매개변수, 함수 중복, 템플릿 함수 |
| `ch4.cpp`, `ch4_final.cpp` | 클래스와 객체 — `Circle` 클래스 선언 · 활용, `string` 클래스 |
| `ch5.cpp`, `ch5_final.cpp` | 생성자와 소멸자, 지역 · 전역 객체의 생성 · 소멸 순서 |
| `ch6.cpp` | `static` 멤버 |
| `ch7.cpp`, `ch7_final.cpp` | 객체 배열(1 · 2차원), 객체 포인터, `new` / `delete` 동적 할당 |
| `ch8_final.cpp` | 값 · 주소 · 참조에 의한 객체 전달, 객체 리턴, 참조 |
| `ch9_final.cpp` | `friend` 함수 · 클래스, 연산자 중복(`+` 등) |
| `ch10_final.cpp` | 상속 — 파생 클래스, 생성자 호출 순서, 기본 클래스 생성자 지정 |
| `ch11_final.cpp` | 가상 함수와 오버라이딩, 동적 바인딩 |
| `ch12_final.cpp` | 템플릿 클래스(제네릭 타입 2개) |
| `midterm_ex.cpp` | 중간고사 대비 연습 |
| `finaltestcpp.cpp` | 기말고사 대비 종합 연습 — 클래스, 동적 할당, 템플릿, STL(`vector`, `map`, `algorithm`) |

환경: Visual Studio (MSVC)
