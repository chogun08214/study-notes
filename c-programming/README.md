# C 프로그래밍 기초

C 교재의 챕터별 예제와 연습문제를 풀어 본 코드입니다. 한 파일에 여러 예제가 들어 있고, 각 예제는 `/* EX1 ... */` 형태의 주석 블록으로 감싸 두었습니다. 실행할 예제 하나의 주석만 풀어서 컴파일합니다.

| 파일 | 주제 | 주요 예제 |
|---|---|---|
| `ch02.c` | C 프로그램 첫걸음 | Hello World, `printf` |
| `ch03.c` | 프로그램 구성 요소 | 변수 선언과 대입, 간단한 계산 |
| `ch04.c` | 자료형 | `sizeof`, 정수 · 실수 · 문자형, 이스케이프 문자, 오버플로 |
| `ch05.c` | 연산자 | 산술 · 나머지 · 증감 · 관계 · 논리 · 비트 연산, 형변환, 우선순위, 윤년 판별 |
| `ch06.c` | 조건문 | `if` / `else`, `switch`, 학점 계산, 문자 분류, 2차 방정식, 계산기 |
| `ch07.c` | 반복문 | `while` / `for`, 구구단, 최대공약수, 숫자 맞히기 게임, 도형 그리기 |
| `ch08.c` | 함수 | 최댓값 · 팩토리얼 · 소수 · 조합, 난수(로또 · 동전 · 자동차 경주), 수학 함수 |
| `ch09.c` | 함수와 변수 | 지역 · 전역 · `static` 변수, 가변 인자, 재귀(팩토리얼 · 최대공약수 · 하노이 탑) |
| `ch10.c` | 배열 | 성적 처리, 주사위 빈도, 선택 정렬, 순차 · 이진 탐색, 2차원 배열 · 행렬, 영상 처리 |
| `ch11.c` | 포인터 | 주소 연산자, `swap`, 포인터와 배열, 함수 포인터 |
| `ch12.c` | 문자열 | 문자 입출력, `strstr` · `strtok` · `sprintf` · `atoi`, 단어 사전, 행맨 |
| `ch13.c` | 구조체 | 학생 정보 구조체, 구조체 배열, 구조체 포인터 |

환경: Visual Studio (MSVC). `scanf` 사용 예제는 `#define _CRT_SECURE_NO_WARNINGS`를 포함합니다.
