# ARM Cortex-M3 (LPC1766) 임베디드 실습

NXP LPC1766 보드에서 주변장치를 직접 제어해 본 실습 코드입니다. `LPC1766.c` 한 파일에 실습 문제별 코드가 주석 블록으로 나뉘어 있습니다.

| 단원 | 주변장치 | 실습 내용 |
|---|---|---|
| 7 | DAC | 250 Hz 펄스 · 톱니파 · 사인파(50샘플 테이블) 출력, 100 Hz→1 kHz로 주파수가 올라가는 사이렌 |
| 8 | UART | 터미널 입력으로 LED 켜고 끄기, LED 상태를 터미널에 표시, 입력한 숫자의 제곱 출력 |
| 9 | 타이머 | 0.5초 주기 LED 점멸, 1 ms · 1초 지연 함수, 두 지연 함수의 시간 차 비교, 3초 알람, 1초마다 증가하는 카운터 |
| 10 | MCPWM | LED 밝기 단계 조절(2 · 4단계), 밝기 반복 주기 변경, 버튼으로 밝기 조절 |

- `#include <LPC17XX.h>` (CMSIS 장치 헤더)와 수업에서 제공한 보조 라이브러리(`ahn_lib.h`)를 사용합니다. 보조 라이브러리는 저장소에 포함하지 않았습니다.
