각 파일에는 개념 설명을 주석으로 정리하고 예제 코드를 함께 작성했습니다.

| `chapter3.py` | 조건문 | if-else, 블록과 들여쓰기, pass |
| `chapter4.py` | 반복문 | for · while, 리스트 기초, 인덱스 |

| `chapter7.py` | 자료구조 II | 튜플, 딕셔너리, 세트, 문자열 |
