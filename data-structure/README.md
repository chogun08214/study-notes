# 자료구조 — 스택을 이용한 미로 탐색

10×10 미로에서 입구 `e`부터 출구 `x`까지 가는 길을 **배열로 구현한 스택**으로 찾는 C 프로그램입니다 (깊이 우선 탐색, DFS).

## 동작 방식

1. 현재 위치를 방문 표시(`.`)합니다.
2. 상 · 하 · 좌 · 우 중 벽(`1`)이 아니고 아직 방문하지 않은 칸의 좌표를 스택에 push합니다.
3. 스택에서 좌표 하나를 pop해 다음 위치로 이동합니다.
4. 출구에 도착하면 "성공!", 스택이 비면 "실패!"를 출력합니다.

단계마다 미로와 스택 상태를 콘솔에 그려 주며, 키를 누르면 다음 단계로 넘어갑니다 (`_getch()`).

## 구성

- `stackobject` 구조체(행 · 열 좌표)와 크기 100의 배열 스택
- `push` / `pop` / `isEmpty`, 이동 가능한 칸만 넣는 `pushLoc`
- `printmaze`, `printstack`으로 탐색 과정 시각화

환경: Visual Studio (MSVC, Windows) — `conio.h`의 `_getch()`를 사용합니다.
